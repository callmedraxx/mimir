Copies of the three no-passage test sets Mimir is scored on (made by `tools/shelf_fetch.py` and
`tools/practice_fetch.py`), so other systems can be run on exactly the same questions
(`tools/laya_arc.py`). Layout: id, question, n options, options..., answer index.

* ARC-Easy / ARC-Challenge test: AI2 Reasoning Challenge (Clark et al. 2018), CC BY-SA 4.0.
* OpenBookQA test: Mihaylov et al. 2018 (Allen Institute for AI), Apache 2.0.
